▣ How to play

🎮 Controls

Most games support WASD / ARROWS + SPACE. Voice games need microphone permission (works best in Chrome / Edge).

🔊 Sound

All audio is synthesized live with the Web Audio API — no MP3s, no samples. Toggle music & SFX inside each game.

💾 Progress

High scores and achievements live in your browser via localStorage. No accounts, no tracking, no cloud.
